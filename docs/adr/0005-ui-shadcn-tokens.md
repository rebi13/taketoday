# 0005. UI는 Tailwind CSS + shadcn/ui, 값은 디자인 토큰으로만

- 상태: 승인
- 날짜: 2026-10-28

## 배경
여러 디자인을 시험해 보고, 나중에 세트 테마처럼 앱 색을 바꾸는 기능까지 확장하고 싶다. 화면의 중심(방, 캐릭터, 미션 카드)은 직접 그리는 요소라 완성형 라이브러리가 덜어주는 부분이 크지 않다.

## 결정
- Tailwind CSS + shadcn/ui. shadcn 컴포넌트는 소스로 `src/shared/ui`에 둔다.
- 색·둥글기·그림자·모션 시간은 역할 이름의 CSS 변수(디자인 토큰)로 한 파일에만 정의하고, 화면 코드에서는 토큰 이름만 쓴다.
- 여러 모양을 가진 컴포넌트는 `cva` 변형으로 정의한다. 상태 이름은 DB 값과 같게 쓴다(`pending`, `done`, `postponed`, `canceled`).
- `/playground`(개발 환경 전용)에 토큰 견본과 모든 변형을 모은다.
- 반응형은 폭 구간(600 미만 / 600~839 / 840 이상)과 `100dvh`, 컨테이너 쿼리로 폴더블까지 대응한다.

## 고려한 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| Mantine v7 | 이미 익숙하고 폼·날짜 컴포넌트가 다 있음 | 기본 인상이 남아 디자인을 갈아엎기 어렵고, 직접 그린 화면과 톤 맞추기 어려움 |
| 라이브러리 없이 직접 | 완전한 자유 | 다이얼로그·바텀시트의 접근성 처리를 직접 해야 함 |

## 결과
- 디자인 변경은 토큰 파일과 `shared/ui`만 보면 된다.
- `bg-[#…]` 같은 직접 값은 리뷰와 린트로 막는다.

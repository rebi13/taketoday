# 0004. 알림은 폴링 대신 예약 메시지로

- 상태: 승인
- 날짜: 2026-10-29

## 배경
사용자마다 정한 시각에 기본 알림을, 21:00에 미처리 추천이 있는 사용자에게 저녁 알림을 보내야 한다. Vercel Hobby cron은 하루 1회까지이고 시각이 최대 59분 어긋난다. Neon Free는 요청이 있을 때마다 깨어나 5분간 컴퓨트를 쓰고, 월 100 CU-hours를 넘으면 다음 주기까지 멈춘다.

## 결정
- 하루 1회 Vercel Cron(`/api/jobs/daily`)이 미접속 사용자 정산과 함께, 다음 24시간의 사용자별 기본 알림을 QStash 지연 메시지로 예약한다.
- 저녁 알림은 QStash 스케줄 하나(매일 21:00 KST)가 대상자를 한 번에 조회해 보낸다.
- 알림 시간·쉬는 날을 바꾸면 그 자리에서 예약을 취소하고 다시 예약한다.

## 고려한 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| 10분마다 알림 작업 실행 (폴링) | 구현 단순 | 호출마다 DB가 깨어나 하루 약 13시간 켜짐, 사용자가 없어도 Neon 무료 한도를 소진 |
| 기본 알림 3시간 뒤 재알림 | 사용자별로 정확 | 사용자당 메시지 2건, 알림 이유가 약함 |
| **예약 메시지 + 21:00 일괄 저녁 알림** | 알림 시각에만 DB가 깨어남, 사용자당 메시지 1건 | 예약 취소·재예약 처리 필요 |

## 결과
- QStash 무료 한도(하루 1,000건)로 사용자 약 900명까지 운영할 수 있다. 근접하면 종량제로 전환한다.
- 알림 정확도는 ±1분.
- 모든 예약 작업은 중복 실행돼도 결과가 같도록 만든다.

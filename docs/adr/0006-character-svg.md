# 0006. 캐릭터는 부위별 SVG + 대기 움직임, 아이템은 AI 생성 이미지

- 상태: 승인
- 날짜: 2026-10-29

## 배경
캐릭터가 가만히 있어도 살아 있는 느낌(숨쉬기, 깜빡임, 귀·꼬리 흔들림)을 주고 싶다. 처음 스타일 가이드는 캐릭터와 아이템 모두 AI로 생성한 한 장짜리 PNG였는데, 한 장짜리 그림은 부위별로 움직일 수 없다.

## 결정
- 캐릭터 3종(먼지토끼, 고양이, 햄스터)은 몸통·눈·입·귀·꼬리를 나눈 SVG로 만들고, Motion으로 대기 움직임과 반응 7종 전환을 구현한다.
- 캐릭터 꾸미기 아이템도 캐릭터의 기준점(head, body, paws)에 맞춘 SVG로 만든다.
- 나머지 아이템은 움직일 필요가 없어 AI 생성 이미지로 만든다.
- "동작 줄이기" 설정이면 멈추고, 화면이 안 보이면 일시정지한다.

## 고려한 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| Rive | 상태 전환이 가장 매끄러움 | 전용 편집기로 애니메이션을 직접 작업해야 함 |
| 프레임 이미지(스프라이트) | 그림체 자유 | AI로 프레임마다 같은 캐릭터를 일관되게 뽑기 어려움 |

## 결과
- 캐릭터 시트와 말투 가이드는 Claude 디자인 캔버스에서 만든다. 시트가 늦어지면 단순 도형 캐릭터로 구조부터 만든다.
- 움직임이 더 필요해지면 같은 SVG를 Rive로 옮기는 것을 검토한다.

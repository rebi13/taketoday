# 0003. 보상은 완료 즉시가 아니라 다음 날 정산으로 지급

- 상태: 승인
- 날짜: 2026-10-28

## 배경
처음 규칙은 "완료하면 즉시 재화 지급, 취소해도 회수하지 않음"이었다. 이러면 완료 → 재화 받기 → 취소를 반복해 미션은 안 한 상태로 두고 재화만 받을 수 있다. 취소한 미션은 마지막 수행일이 갱신되지 않아 다음 날 또 추천되므로 매일 반복도 가능하다.

## 결정
완료하면 "적립 예정"으로만 보여주고, 한국 시간 자정에 그날의 완료를 정산해 다음 날 지급한다.
- 정산 규칙: 취소된 완료 제외 → 완료 시각 순 → 미션별 첫 1건 → 앞에서 10건.
- 취소는 완료한 날 안에서만 가능하다.
- 정산은 (사용자, 날짜) 유니크 제약으로 한 번만 실행된다. 다음 날 첫 요청 때 정산하는 지연 정산을 기본 경로로, Vercel Cron을 백업으로 둔다.

## 고려한 대안
| 대안 | 장점 | 단점 |
|---|---|---|
| 즉시 지급 + 취소 시 회수 | 보상이 즉각적 | 이미 쓴 재화를 회수하면 잔액이 음수가 될 수 있음 |
| 즉시 지급 + 취소한 완료도 상한에 포함 | 구현 단순 | 같은 미션으로 매일 반복하는 어뷰징은 막지 못함 |
| **다음 날 정산** | 취소·재완료 처리가 단순하고 잔액 음수가 없음 | 보상이 늦게 옴 |

## 결과
- 보상감은 완료 순간의 캐릭터 반응과 "적립 예정 +10" 표시, 다음 날 "어제 보상 도착" 연출로 유지한다.
- 오프라인 완료는 누른 시각의 날짜로 처리하되, 이미 정산된 날짜면 받지 않는다.
- 실제로 하지 않고 완료를 누르는 것은 막을 수 없다. 하루 10회 상한이 최대 이득을 묶는다.
